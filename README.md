# mobile-recharge-sim-gateway-telecom-mfs-robotic
Autonomous robotic SIM gateway &amp; mobile recharge API built with Laravel. Supports USSD automation, multi-SIM hardware pooling, bKash/Nagad/Rocket MFS cash-in, carrier auto-detection (GP, Robi, BL, Airtel, Teletalk), and instant regex SMS/OTP parsing.
